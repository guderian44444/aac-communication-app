## Variant: 結構網格版 (Structured Grid)

### 設計理念
清晰、結構化、工具導向 — 像 PECS 溝通板的數位版本。

### 關鍵設計選擇
- **配色**: 深色主題（深蓝背景），減少光線刺激
- **佈局**: 左側欄分類 + 右側網格，結構明確
- **對比**: 高對比色彩，邊框顏色標示分類
- **句子欄**: 突出顯示在上方，操作按鈕大而明確
- **風格**: 幾何感強，少裝飾元素

### 優勢
- 結構清晰，適合偏好規律的使用者
- 深色主題減少光線刺激（對光敏感者友好）
- 分類邊框顏色編碼，一目了然

### 劣勢
- 深色主題可能對部分兒童造成不安
- 幾何風格較少「童趣感」

### 適合
- 偏好結構和規律的自閉兒童
- 對光線敏感的使用者
- 較大兒童（7歲+）或青少年
