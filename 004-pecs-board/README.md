# PECS 溝通板版

## 設計理念
模擬真實 PECS（圖像交換溝通系統）治療板 — 臨床驗證最有效的 AAC 方式。

## 關鍵設計選擇
- **佈局**: 模擬實體溝通板，卡片帶魔鬼氈視覺效果
- **配色**: 中性灰白背景 + 藍色主色，不干擾視覺
- **快捷列**: 底部固定常用詞（吃飯、喝水、廁所、可以、不要...）
- **句子條**: 點擊後顯示帶圖示的詞條，模擬 PECS 卡片排列
- **風格**: 專業、臨床、直覺

## 優勢
- 與 PECS 治療法無縫銜接，臨床師推薦
- 底部快捷列讓最常用詞一鍵觸及
- 中性配色，適合各種環境

## 適合
- 正在接受 PECS 訓練的兒童
- 需要與治療法銜接的家長/特教老師
