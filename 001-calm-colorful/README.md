## Variant: 柔和色彩版 (Calm & Colorful)

### 設計理念
溫暖、柔和、不具威脅感 — 讓自閉兒童感到安全和舒適。

### 關鍵設計選擇
- **配色**: 柔和漸層背景（暖白→淡藍），每分類有專屬柔和底色
- **圓角**: 大圓角卡片（20px），無銳利邊角
- **動畫**: 輕微的彈跳動畫，不閃爍
- **排版**: 句子欄使用漸層紫色標籤，清晰可辨
- **導航**: 頂部分類標籤 + 底部導航列

### 優勢
- 視覺壓力低，適合高敏感使用者
- 分類色彩編碼，幫助快速定位
- 即時回饋（彈跳動畫）強化點擊感

### 劣勢
- 資訊密度較低
- 柔和配色可能在低亮度螢幕上對比不足

### 適合
- 年幼兒童（3-7歲）
- 對視覺刺激敏感的自閉兒童
